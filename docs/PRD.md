# Product Requirements Document (PRD)
**EduFlow SaaS Platform**

---

## 🎯 Product Overview

EduFlow is an enterprise SaaS platform built for professional classroom coaching, video courses streaming, live classes, assignment tracking, and auto-graded assessments.

---

## 🚀 Key Feature Categories

### 1. Curriculum Builder & HLS Video Player
- Dynamic builder for courses, modules, chapters, and lessons.
- Automated local FFMPEG processing that transcodes uploads into multi-resolution HLS streams (`.m3u8` lists) in the background.
- Custom premium video player on the frontend supporting playback rate, video seeking controls, auto-resume watch times, and progress monitoring.

### 2. Live Class Coordinator
- Automated meeting adaptor scheduling join URLs for Zoom, Google Meet, and LiveKit.
- Unified calendars displaying upcoming live sessions.

### 3. Assessments & Exams
- Assignments submissions tracking with grading feedback from teachers.
- Online exam engines scoring MCQ responses against correct option keys in real-time.

### 4. Interactive Chat
- Messaging UI permitting student-teacher communication.
